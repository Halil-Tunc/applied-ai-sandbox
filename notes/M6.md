# M6 — Other Tools Tour

## Copilot — installed
- Observation: Copilot worked well for small inline code suggestions while typing in VS Code, but it felt less project-aware than Claude Code because it mainly reacted to the current file and nearby context.

## Cursor (or Windsurf) — demo'd
- Observation: Cursor seems strongest when I want the editor and AI agent in one place, especially for reviewing or applying multi-file diffs visually, while Claude Code feels better when I am already working from the terminal and want the agent to run commands.

## Gemini CLI — installed but auth-blocked/demo'd
- Same prompt comparison: Gemini CLI installed successfully, but Google sign-in was blocked because the account was not eligible for Gemini Code Assist for individuals. Based on the install attempt and demo fallback, Gemini CLI has the same terminal-agent shape as Claude Code, but Claude Code felt more usable for this cohort because authentication worked and it could immediately read the repo and run commands.

## ChatGPT — used for code review
- Observation: ChatGPT was useful for reviewing the M5 Task 1 diff because it flagged that future tag-related code should handle older notes that may not have a `tags` key yet.

## Tool decision matrix
| Situation | Tool I'd reach for | Why |
| --- | --- | --- |
| Multi-file feature with good CLAUDE.md | Claude Code | It can read project files, follow repo-specific instructions, edit multiple files, and run commands/tests. |
| 5-line helper autocomplete while typing | GitHub Copilot | Inline autocomplete is faster than writing a full prompt for a small helper. |
| Brainstorm three design approaches | ChatGPT or Claude.ai | Chat is good for planning and comparing options before touching code. |
| Review a teammate's PR for security issues | ChatGPT or Claude.ai | Pasting a diff into chat is useful for spotting risks, missing edge cases, and security concerns. |
| Cross-file refactor with consistent renames | Cursor or Claude Code | Cursor is useful for visual multi-file diffs, while Claude Code is strong if I want terminal-based edits and tests. |
| Learning a new library's API | ChatGPT or Claude.ai | Chat can explain concepts, show examples, and answer follow-up questions without changing the repo. |
