# M6 — Other Tools Tour

## Copilot — installed
- Observation: Copilot worked well for small inline code suggestions while typing in VS Code, but it felt less project-aware than Claude Code because it mainly reacted to the current file and nearby context.

## Cursor (or Windsurf) — demo'd
- Observation: Cursor seems strongest when I want the editor and AI agent in one place, especially for reviewing or applying multi-file diffs visually, while Claude Code feels better when I am already working from the terminal and want the agent to run commands.

## Gemini CLI — installed but auth-blocked/demo'd
- Same prompt comparison: Gemini CLI installed successfully, but Google sign-in was blocked because the account was not eligible for Gemini Code Assist for individuals. Based on the install attempt and demo fallback, Gemini CLI has the same terminal-agent shape as Claude Code, but Claude Code felt more usable for this cohort because authentication worked and it could immediately read the repo and run commands.
